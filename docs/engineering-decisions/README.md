## Format

Each ADR documents:

- **Context** — problem or requirement
- **Decision** — what we chose
- **Rationale** — why
- **Consequences** — trade-offs
- **Alternatives considered** — what we rejected and why

New decisions get the next sequential number. Do not renumber existing ADRs.
