# Visual guideline — Medium light

HTML/CSS owns geometry and copy. No generated pixels.

- Background `#ffffff`
- Ink `#1c1917`, muted `#78716c`
- Accent copper `#b45309` / `#9a3412` on `#fff7ed` (same role as the talk deck gold, inverted for a white post)
- Dashed grey = unchanged / outer-loop leftover
- Solid copper = this era actually changed the stage
- `human` is black bold; `agent` is copper bold
- No slide titles, no “LIVE EXCERPT” pills
- Type: system UI sans; commands in mono
